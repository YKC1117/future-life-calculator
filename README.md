# 未來生活試算

公開版退休試算工具，核心流程：
1. 退休收入：勞保老年年金、勞退新制、國民年金快速估算並加總。
2. 生活缺口：比較退休月收入與希望的退休生活費。
3. 未來準備：用現有資金、每月準備、年數與假設報酬率做情境試算。
4. 重點整理：即使資料未填完整，也會依目前已提供內容整理；未填欄位不會自動當成 0。

## 建議使用方式：網址 + PWA 離線
最推薦將整個資料夾部署到 GitHub Pages，取得一個 HTTPS 網址。

### iPhone / iPad
1. 用 Safari 開啟網站網址。
2. 點「分享」。
3. 選「加入主畫面」。
4. 之後可像 App 一樣從桌面開啟。第一次成功載入後，核心頁面可離線使用。

### Android
1. 用 Chrome 開啟網站。
2. 選單中選「加到主畫面」或「安裝應用程式」。
3. 之後從桌面圖示開啟。

### 同事共用
只要把公開網址傳給同事即可。每位同事都可以各自在自己的手機 / 平板加入主畫面。輸入資料只在當下頁面計算，不會自動上傳或建立共同客戶資料庫。

> 若網址是公開的，任何拿到網址的人都能開啟。若未來需要限制公司內部使用，應另外加登入或密碼保護。

## PDF / 報告
- 「整理目前已填資料」：即使資料不完整，也會整理現有內容。
- 「下載／儲存 PDF」：使用裝置的列印功能產生 PDF。
- iPhone / iPad：開啟列印預覽後，可透過分享功能儲存到「檔案」或傳送。
- Android / Windows / macOS：在列印目的地選「另存為 PDF / Save as PDF」。
- 「下載 HTML」：另外保留一份可重新開啟閱讀的報告檔。

## 資料與隱私
- 不使用帳號或資料庫。
- 不自動將輸入內容上傳至雲端。
- 不自動建立或保存客戶檔案。
- 關閉或重新整理後，頁面輸入內容不保證保留。

## 重要
本工具為簡易試算工具，不等於官方核定。勞退新制快速月領採概略方式呈現；正式月退休金及各項退休給付仍應以主管機關最新規定與正式核定結果為準。
